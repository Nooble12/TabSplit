A simple app that calculates a per-person bill based on sales tax, tip, and service fee.
Built using .NET 10 and WPF.

# Update: 10/8/2026
Added an item catalog system that allows users to define items once and select them when adding items to a person's inventory, eliminating the need to re-enter the same item information for each person.  
Note: Updating the catalog item does not replicate to items already in the person's inventory. Items added to an inventory from the catalog are copies / a snapshot.  
Users may also create person-specific items if they wish (original system).
